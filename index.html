Sobre el proyecto

¿Qué es Tarea Bulma?

Tarea Bulma es un sitio web académico creado para practicar el uso del framework Bulma. La página combina navegación, columnas, tarjetas, botones y formularios.

Bulma proporciona clases CSS listas para utilizar, lo que facilita la creación de interfaces claras y adaptables a diferentes pantallas.

Este proyecto utiliza HTML para la estructura, Bulma para los estilos y JavaScript para algunas interacciones.
